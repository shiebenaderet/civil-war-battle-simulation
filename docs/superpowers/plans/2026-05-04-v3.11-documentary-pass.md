# v3.11 "Documentary Pass" Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Re-skin the simulation from "edtech 2021" Blooket aesthetic to a "Field Report" period-newspaper aesthetic. No structural change — same screens, same content, same flow. Just a different worldview.

**Architecture:** Single-pass CSS rewrite of the design tokens (palette, fonts, radii, shadows) plus targeted markup edits in `index.html` to remove emoji-prefixed headings and add masthead-style structures. Drop the dark theme entirely (sepia is the only theme). Replace one Google Fonts request. No JS architecture changes; only theme-toggle JS removal.

**Tech Stack:** Vanilla HTML/CSS/JS, no build, runs from `file://`. Google Fonts via `<link>`. Dark theme is being removed; one theme only.

**Aesthetic direction (locked from mockup `aesthetic-directions.html`, Direction B):**
- **Background:** sepia paper (`#f0e9d8`), elevated paper (`#ebe2cb`), card paper (`#f5efde`)
- **Text:** ink (`#1a1611`), muted ink (`#4a3f2c`), faint ink (`#7d6e54`)
- **Accent:** vermillion (`#6b1a17`) used sparingly for primary actions and key highlights
- **Rules:** soft tan (`#c4b89a`) for borders and dividers
- **Body type:** Old Standard TT (period serif), 15–17px, line-height ~1.55
- **Display type:** Old Standard TT 700 weight at heading sizes; uppercase with negative tracking for mastheads
- **Accent type:** Special Elite (typewriter), used ONLY for: top-meta dispatch lines, hero captions, section labels, choice button letters (A/B/C). Never body, never headings, never instructions.
- **Chrome:** double-rule mastheads (`border-bottom: 4px double var(--ink)`), sepia photo borders (1px solid ink + 0.4rem padding), inline section labels as inverted ink-on-paper pills.

**Risks (named, with mitigations):**
1. **Reading fatigue at scale.** Mockup is one screen; production is 13 battles × 4 steps. Mitigation: keep body copy at comfortable size + line-height, restrict typewriter font to chrome only, never body.
2. **Sepia + small text on Chromebook screens may have contrast issues.** Mitigation: ink color is `#1a1611` on `#f0e9d8` paper — passes WCAG AA at 14px+. Verify in Task 11.
3. **Removing dark theme is a one-way door.** Verified the user wants this in chat. If reversed later, it's a new ticket.
4. **Free-play screens use the same tokens** — re-skinning Historical also re-skins Free-play, even though Free-play is being moved out of the launch path in v3.15. Acceptable: Free-play still benefits from the new look.
